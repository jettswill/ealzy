# Ealzy для iOS

Нативное приложение-«дом» Илзи (план — `research/ios-app-plan.md` в проекте). Тонкий клиент
к тому же API, что сайт и Telegram-бот: аккаунт, дела, люди и память общие.

## Что есть в v0.1

- Вход через Telegram (одноразовая ссылка на бота, `/api/auth/app-login/*`) или Google
  (`/api/auth/oauth/google/start?client=ios` → `ealzy://auth/callback`).
- Экран «Сегодня»: фокус (1, максимум 2), просрочено, сегодня, мелочи, «Илзи делает сама»,
  «в запасе N». Логика — `Ealzy/Core/DayPlanner.swift`, тесты — `EalzyTests`.
- Быстрая запись «Скажи Илзи» — уходит в чат, Илзи сама ставит дату и время.
- Чат с Илзи — тот же разговор, что в Telegram.
- Точные напоминания: локальные уведомления ко времени дела с кнопками
  «Готово / Через 15 минут / Вечером / Завтра»; дела «только на день» (полдень) не звенят.
  Фоновое обновление переставляет напоминания для дел, записанных в других местах.

## Сборка

Проект Xcode генерируется из `project.yml`:

```sh
brew install xcodegen
cd apps/ios && xcodegen generate && open Ealzy.xcodeproj
```

CI (`.github/workflows/ios.yml`) на каждый PR собирает приложение для симулятора без подписи
и гоняет тесты. Выкладка в TestFlight появится после аккаунта Apple Developer
(нужны Team ID и ключ App Store Connect в секретах GitHub).
