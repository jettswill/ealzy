# База мест из Guide-App

Источник: старый проект Guide-App (gidmyshlen.ru / randomyourlife.ru), продовая база,
бэкап `Guide-App/database-backups/march11_restored.sql` (11.03.2026). Живой сайт на 18.11.2026 отвечает 502.

- `places.json` — категории, типы мест (с рейтингами активности/эмоций, возрастом, числом участников) и 527 мест с координатами.
- `places.csv` — те же места плоской таблицей (открывается в Excel/Numbers).

Города: Москва 294, Санкт-Петербург 222, Новосибирск 10.
Типы: верёвочные парки, картинг, детские парки, скалолазание, флоатинг, мафия, сайкл, боулинг,
гоночные симуляторы, пляжный волейбол, антистресс, прятки в темноте, иммерсивный театр, джаз-клубы и др.
Кофеен/ресторанов в базе нет — их Илзи будет подтягивать через 2ГИС (парсер есть в Guide-App/backend/src/controllers/parserController.js).

Пересобрать: `python3 parse.py <dump.sql> places.json` (скрипт в этой папке).
